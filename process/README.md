# 制作過程

このリポジトリでは、ブログ用キャラクターなどの画像を生成したときだけ制作過程を記録する。
画像生成以外の作業では、ユーザーが明示的に求めた場合を除き、制作過程の作成・追記は不要。
リポジトリの決まりの正本は `../CLAUDE.md`。

既存の制作過程は2026-10-12にユーザーの指示で削除した。
生成済みのリスの原寸画像と生成情報は `../assets/img/blog-character/` に保存している。

- [プロフィール画像のドット絵](profile_pixel.md): 元のリスをもとにした128×128pxと64×64pxの生成案。

- [ファビコン](favicon.md): 変更前から現在までの変更を拡大・タブサイズで比較。途中の版は作業ログから復元。
