思考カテゴリの目次の制作過程

カテゴリに応じた目次表示（2026-10-11）

1. 思考カテゴリでは目次を非表示

テーマの single.html を layouts/_default/single.html に上書き用テンプレートとして配置。「思考」をカテゴリに含む記事では目次と目次用の欄を出力しない。PC・スマホ共通で、記事ごとの表示設定より優先する。他のカテゴリは従来の設定を使用する。

…
      {{ $enableToc := site.Params.article.showTableOfContents | default false }}
      {{ $enableToc = .Params.showTableOfContents | default $enableToc }}
      {{ if in (.Params.categories | default slice) "思考" }}
        {{ $enableToc = false }}
      {{ end }}
      {{ $showToc := and $enableToc (in .TableOfContents "<ul") }}
      {{ $topClass := cond (hasPrefix site.Params.header.layout "fixed") "lg:top-[140px]" "lg:top-10" }}

2. 新しい記事を思考カテゴリに設定

「AIの普及と規制」を既存の思考記事と同じカテゴリに設定した。本文はそのまま保持する。

…
draft = true
title = 'AIの普及と規制'
categories = []
categories = ["思考"]
